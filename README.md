# Java Huffman Compression Tool

A Java-based file compression and decompression tool using the **Huffman Coding algorithm**.

## 🚀 Features

- File compression using Huffman Coding
- File decompression and restoration
- Java-based backend
- HTML-based web interface
- Local HTTP server using Java
- Lossless compression

## 🛠️ Technologies Used

- Java
- HTML
- Huffman Coding
- HTTP Server

## 📂 Project Structure

- `HuffmanCompressor.java` – Handles Huffman compression and decompression.
- `HuffmanServer.java` – Runs the local HTTP server and connects the backend with the web interface.
- `HuffmanCompressor.html` – Provides the web-based interface.

## ▶️ How to Run

1. Compile the Java files.
2. Start the `HuffmanServer`.
3. Open the provided localhost URL in a web browser.
4. Use the interface to compress or decompress files.

## 🎯 Objective

The project demonstrates how the Huffman Coding algorithm can be used to perform lossless file compression while providing a simple web-based interface for users.
